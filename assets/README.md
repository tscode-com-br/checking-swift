# Capturas para a App Store

As imagens prontas para envio estão em:

`app-store/pt-BR/iphone-6.5/`

## Ordem recomendada

1. `01-tela-principal.jpg`
2. `02-atividades-automaticas.jpg`
3. `03-historico-check-in.jpg`
4. `04-ajustes.jpg`
5. `05-pausa-programada.jpg`
6. `06-notificacoes.jpg`

As três primeiras apresentam, nesta ordem, a experiência principal, o funcionamento automático em segundo
plano e o histórico das atividades. Essa ordem também será usada nas planilhas de instalação exibidas pela
Apple.

## Validação técnica

- dispositivo representado: iPhone 14 Plus, tela de 6,5 polegadas;
- orientação: retrato;
- resolução: 1284 × 2778 pixels;
- formato: JPEG;
- espaço de cores: RGB;
- transparência/canal alfa: ausente;
- idioma: Português (Brasil);
- horário e estado da bateria padronizados;
- chave fictícia `DEMO` e senha ocultada na tela principal;
- nenhuma credencial real, coordenada ou dado pessoal foi incluído;
- nenhuma ferramenta de validação física aparece nas imagens.

## Envio

No App Store Connect, abra a versão do app, localize **Pré-visualizações e capturas de tela do app**,
selecione a área de iPhone de 6,5 polegadas e arraste os seis arquivos na ordem numérica acima.

A Apple aceita de uma a dez capturas em JPEG ou PNG. Quando a interface é a mesma nos demais iPhones, as
imagens de maior resolução são redimensionadas automaticamente para os tamanhos menores.
